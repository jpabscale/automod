    ~mods — the game's installed-mod folder. The manager writes the merged overlay, trimmed mods, and its backup/state files here. It should be inside SB/Content/Paks.

    Mod archives folder — the folder containing your original .zip/.7z/.rar downloads. Used to import, reorder, and restore mods; dropped archives are saved here. Nothing is uploaded.

    Manage Stellar Blade mods entirely in your browser. Select your ~mods and mod-archives folders; all reads, merges, and writes stay on this device.

    • Drag-and-drop priority with per-property pins
    • DataTable row merging plus per-asset merge
    • Support .zip, .7z, and .rar mod archives
    • Trim losing chunks; source archives are the backup
    • Agent API with None, Agent, and Agent+ modes

    Agent modes: None disables the agent API. Agent lets the agent inspect, edit the draft, and plan, but apply/uninstall need your approval. Agent+ applies and uninstalls automatically. Back up ~mods before uninstalling.
